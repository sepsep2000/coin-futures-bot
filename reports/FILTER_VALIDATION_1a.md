# FILTER_VALIDATION_1a.md — 1a(1D 모멘텀 정합) 필터 학습/홀드아웃 재현성 검정

1a는 신호 자체로는 RECLASSIFY_AS_FILTER 판정을 받았다(trend와 상관계수
0.876, 활성구간 100% 중첩 — SIGNAL_VALIDATION_1a.md). 남은 질문은
"trend의 필터로서 이 개선폭이 특정 기간의 우연이 아니라 일반화되는가"다.
판정 기준은 결과를 보기 전에 확정했다(SIGNAL_CATALOG_V2.md 참조): 홀드아웃
구간에서 필터 적용 PF와 평균R이 **둘 다** 필터 미적용 대비 개선돼야
재현 인정. 원본 데이터: `reports/diag_data/filter_1a_*.csv`.

## 해석

홀드아웃 구간에서 PF 개선폭(+0.411)과 평균R 개선폭(+0.171) 모두 학습
구간(+0.228, +0.116)보다 **오히려 크다** — 필터를 한 번도 보지 않은
기간에 그대로 적용해도 개선 효과가 사라지지 않고, 이번 경우엔 더 크게
나타났다. 두 지표(PF, 평균R) 모두 두 구간에서 일관되게 같은 방향(개선)을
가리킨다 — 과최적화의 전형적 징후(학습에서만 좋고 홀드아웃에서 사라지는
패턴)가 보이지 않는다.
